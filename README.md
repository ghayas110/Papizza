# Papizza

A pizza ordering site built with Next.js 16, TypeScript, Tailwind CSS v4 and Framer Motion. There's no backend: every menu item can be configured and added to the cart, and checkout opens WhatsApp with the whole order already typed out.

## Run it

```bash
npm install
cp .env.example .env.local   # then set NEXT_PUBLIC_WHATSAPP_NUMBER
npm run dev
```

`NEXT_PUBLIC_WHATSAPP_NUMBER` is the chat that receives orders, in international format with digits only (for example `923001234567`). If you leave it empty, WhatsApp asks the customer which chat to send the order to.

## How it works

- **Menu data**: `src/data/menu.json`, generated by `scripts/build-menu.mjs` from the raw scrape in `data/broadway-products.json`. It has 58 items in 10 categories, with sizes, crusts, flavors, toppings and deal contents.
- **Cart**: a Zustand store saved to `localStorage` (`src/lib/stores.ts`). Each cart line keeps a snapshot of its name, picks and price.
- **Checkout**: `src/lib/whatsapp.ts` builds the message, and `src/lib/site.ts` builds the `wa.me` link.
- **No server code**: the page is prerendered as static HTML.

## Refreshing the menu

```bash
node scripts/scrape-broadway.mjs   # reads the public /product/ pages listed in the sitemap
node scripts/build-menu.mjs        # rebuilds src/data/menu.json
```

## Before going live

- Item names, prices and deal contents come from Broadway Pizza's public menu (scraped 2026-10-07). Replace or confirm them with your own menu before launch.
- Food photos are from Unsplash and are free to use under the Unsplash License. `data/image-meta.json` lists the Unsplash photo ID and photographer for every image.
- Descriptions were rewritten without the source brand. Where the source had none, the copy describes what the item contains.
